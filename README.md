# Anastasi-Design — Portfolio

UI/UX-портфоліо: проєктую інтерфейси мобільних застосунків, від перших флоу до готових до розробки екранів. Сайт двомовний (UA/EN) і показує навчальні кейси, спосіб роботи та орієнтовні ціни.

**Сайт:** [anastasi-design.gallery](https://anastasi-design.gallery)

## Технології

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com)
- Дизайн із Figma, перенесений у код через Figma MCP
- Деплой на [Vercel](https://vercel.com)

## Розробка

```bash
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000), щоб побачити результат.
